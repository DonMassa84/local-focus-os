# Recruiter Summary

## Project

Local Focus OS

## One-Sentence Summary

Local Focus OS is a privacy-first Linux workflow automation system that turns brain dumps into structured tasks, schedules local routines through systemd timers, creates Markdown reports and optionally integrates local AI through Ollama.

## Safety Model

The system is intentionally limited.

It does not automatically:

- send emails
- push to GitHub
- delete user data
- submit documents
- claim confirmations or external replies

External actions require human review.
