# TALK Communication Workflows

Dieses Modul enthält Kommunikations-Templates auf Basis des TALK-Frameworks:

- **T — Topics:** Gesprächsthemen aktiv steuern
- **A — Asking:** präzise Fragen und Follow-ups einsetzen
- **L — Levity:** Spannung reduzieren und Gespräch anschlussfähig halten
- **K — Kindness:** respektvoll, klar und wirksam kommunizieren

## Zweck

Die Templates unterstützen strukturierte Kommunikation in:

- Gesprächsvorbereitung
- Konfliktklärung
- E-Mail-Prüfung vor dem Senden
- High-Stakes-Reframing
- Wochenkontrolle
- Führungs- und Feedbacksituationen
- Bewerbungs-, Behörden- und Projektkommunikation

## Sicherheitsregel

Dieses Modul enthält nur generische Templates. Persönliche Daten, Rohdaten, Logs, Namen, Adressen, Telefonnummern, IBANs, Tokens, API-Keys und private Kommunikation dürfen nicht veröffentlicht werden.
