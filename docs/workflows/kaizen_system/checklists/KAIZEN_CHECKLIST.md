# Kaizen Checklist

## Daily

- [ ] Brain Dump erstellt
- [ ] Daily Highlight gesetzt
- [ ] Micro-Commitment definiert
- [ ] Sprint gestartet
- [ ] Ergebnis dokumentiert
- [ ] Blocker notiert
- [ ] nächster Schritt klar

## Weekly

- [ ] Fortschritte geprüft
- [ ] wiederholte Blocker erkannt
- [ ] Prioritäten bereinigt
- [ ] nächste Woche geplant
- [ ] unnötige Aufgaben gestrichen
- [ ] Automatisierungspotenzial erkannt

## Sicherheitscheck

- [ ] keine Tokens
- [ ] keine API-Keys
- [ ] keine Passwörter
- [ ] keine privaten Logs
- [ ] keine personenbezogenen Rohdaten
- [ ] keine Behörden-/Finanzdaten
