# Kaizen System Runbook

## Ziel

Das Kaizen-System erzeugt tägliche Umsetzung trotz hoher Aufgabenlast.

## Ablauf

### 1. Brain Dump

Alle offenen Gedanken und Aufgaben werden gesammelt.

### 2. Highlight setzen

Eine Priorität wird ausgewählt.

### 3. Micro-Commitment definieren

Der Einstieg wird so klein gewählt, dass kein Widerstand entsteht.

### 4. Sprint starten

Ein kurzer Arbeitsblock wird ausgeführt.

### 5. Ergebnis dokumentieren

Output zählt mehr als Absicht.

### 6. Korrektur durchführen

Fehler werden als Steuerungsdaten genutzt.

## Minimalversion

Wenn wenig Energie vorhanden ist:

1. Eine Aufgabe notieren
2. Zwei Minuten starten
3. Ergebnis speichern

## Qualitätsregel

Jeder Kaizen-Durchlauf endet mit sichtbarem Text, Datei, Commit, Checkliste oder nächstem Schritt.
