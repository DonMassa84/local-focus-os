# Regular Operations Workflows

Dieses Modul enthält kuratierte, wiederverwendbare Workflows für regelmäßige IT-Operations-Routinen.

## Zweck

Die Workflows unterstützen lokale, wiederholbare Betriebsprozesse in Local Focus OS:

- Daily Report Automation
- Guardrail Checks
- Workflow Review
- Dashboard- und Status-Standards
- Git-Sync-Status
- OCR Watcher Service
- Daily Document Updater
- LoRA Training Evaluation Status
- System Control
- Evening Check

## Prinzip

Die Workflows sind als generische, dokumentierte Vorlagen gedacht. Sie sollen operative Routinen nachvollziehbar, prüfbar und wiederholbar machen.

## Sicherheitsregel

Vor Veröffentlichung dürfen keine persönlichen Rohdaten, Logs, privaten Pfade mit sensiblen Inhalten, Tokens, API-Keys, Passwörter, E-Mail-Adressen, Telefonnummern, IBANs oder Behörden-/Kundennummern enthalten sein.
