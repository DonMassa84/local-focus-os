# Workflow Review Checklist

## Pflichtpunkte
- [ ] Situation beschrieben
- [ ] SMART-Ziel formuliert
- [ ] Stakeholder genannt
- [ ] Ursachen nach Human / Organization / Process getrennt
- [ ] Alternativen A/B/C bewertet
- [ ] Economic / Human / Organizational bewertet
- [ ] Entscheidung begründet
- [ ] Umsetzung mit Trigger, Inputs, Steps, Outputs dokumentiert
- [ ] KPIs definiert
- [ ] Review- und Korrekturmechanismus vorhanden
- [ ] Nachhaltigkeit beschrieben
- [ ] Discord-Kurzfassung vorhanden
- [ ] Wikimemo-Seite vorhanden
- [ ] Runbook vorhanden
- [ ] Legal/Security Risk geprüft

## Produktiv-Freigabe
- [ ] Lokal getestet
- [ ] Logs vorhanden
- [ ] Keine Secrets veröffentlicht
- [ ] Backup/Recovery bekannt
- [ ] Owner gesetzt
- [ ] Review-Datum gesetzt
